# Temperature Converter

## SkillCraft Technology – Software Development Internship

### Task 01: Temperature Converter

This Python program converts temperatures between three scales:

- Celsius
- Fahrenheit
- Kelvin

### Features
- Convert between all three temperature scales.
- Accept decimal and negative temperature values.
- Validate temperature scale inputs.
- Display conversion results.

### How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python temperature_converter.py
```
